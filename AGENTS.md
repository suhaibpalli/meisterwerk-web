# Meisterwerk — project rules

Everything below this line is project-specific and hand-written. The block above is generated by `next dev` — leave it alone, commit it with your work.

## What this is

A marketing website for **Meisterwerk Fitout LLC**, a Dubai-based luxury retail fit-out contractor. They build and renovate boutiques for hard-luxury maisons — Van Cleef & Arpels, Bvlgari, Cartier, Tiffany, Piaget, A. Lange & Söhne, Jaeger-LeCoultre, IWC, Chaumet, Hermès.

**They are not an interior design firm.** The maison's own architects fix the design; Meisterwerk executes it to tolerance, inside a live trading mall, usually overnight. The site sells *fidelity, logistics, finish and speed* — not creative vision. Copy and art direction must reflect that. Macro material detail (brass reveals, lacquer edges, stone junctions, joinery seams) proves fit-out; wide store shots prove nothing and look like every competitor.

Replaces the existing WordPress single-page site at meisterwerk.ae.

## Design direction

Dark, minimal, Swiss-precision editorial. The reference register is a shop drawing rendered in negative: strict grid, hairline rules, real typographic hierarchy, monospace for specification data.

- **Restraint reads as more expensive than motion.** Slow, long eases. No bounce, no springs, no spectacle.
- Near-black ground — **never `#000`**.
- One accent, used about three times per page.
- Two typefaces maximum.
- If a component has a gradient border, a glow, or a shimmer, it is wrong for this project.

## Hard rules

**Never introduce, without being asked:**

- **Motion / Framer Motion.** GSAP is the animation runtime. Two runtimes on one page is a synchronisation and bundle problem. If shared-element page transitions are needed, use React's `<ViewTransition>`.
- **ScrollSmoother or `ScrollTrigger.normalizeScroll(true)`.** Both do Lenis's job and fight it. Lenis is the choice.
- **locomotive-scroll.** v5 is just a layer over Lenis, which we already have.
- **`@studio-freight/lenis`.** Dead package. The `studio-freight` org is empty; everything moved to `darkroomengineering`. Install `lenis`.
- **`basementstudio/scrollytelling`.** Last pushed Feb 2024, predates React 19 and mature `useGSAP`.
- **Barba.js.** It swaps `innerHTML` for multi-page apps. In App Router the router owns navigation and React owns the DOM.
- **`next-view-transitions`.** Redundant on Next 16 — use React's `ViewTransition` directly.
- **Magic UI, Aceternity UI, HeroUI.** Their entire vocabulary — shimmer, beams, meteors, tracing borders, spotlight cards — reads as generic AI-startup. It is the opposite of this brief.
- **three.js / R3F.** Not in scope, not in budget. ~150kb before you write anything and the biggest LCP/INP threat on the page.

**shadcn/ui is allowed but only for behaviour** — Dialog, Popover, Accordion, focus management, keyboard nav. Strip every pixel of its default styling. Its `rounded-lg` / `border` / `muted-foreground` look is the most recognisable generic-startup signature on the web.

## Next.js 16 — things that differ from older training data

- **Tailwind v4 is CSS-first.** There is no `tailwind.config.ts`. Tokens live in `@theme` inside `src/app/globals.css`. Anything copied from a Tailwind v3 project needs translating.
- **`experimental.ppr` no longer exists.** Partial prerendering is delivered through Cache Components (`cacheComponents: true`) and the `"use cache"` directive.
- **`middleware.ts` is now `proxy.ts`.**
- **`next lint` was removed.** There is no lint script in this project.
- **`images.qualities` must be declared explicitly**, default `[75]`. A `quality={85}` prop outside the allowlist is silently coerced. Declare `[75, 85]` in `next.config.ts` before using 85.
- **`images.domains` is deprecated** — use `remotePatterns`.
- **Automatic `scroll-behavior: smooth` was removed.** Good — we want it off anyway, Lenis owns scrolling.
- `params`, `searchParams`, `cookies()` and `headers()` are **async only**.
- Turbopack is the default bundler for dev and build.

## GSAP + Lenis rules

**The wiring, exactly:**

```
lenis.on('scroll', ScrollTrigger.update)
gsap.ticker.add((time) => lenis.raf(time * 1000))
gsap.ticker.lagSmoothing(0)
```

`gsap.ticker` passes **seconds**; Lenis wants **milliseconds**. Omitting `* 1000` is the single most common bug in this stack — scrolling appears frozen.

**Every animation goes inside `useGSAP()`.** It wraps the callback in a `gsap.context()` and reverts on cleanup, which is what makes React's dev double-mount harmless. Rules:

- Always pass `{ scope: containerRef }` so selector strings resolve inside the component. Without it, a second instance animates the first one's nodes.
- Set `revertOnUpdate: true` on anything keyed to state (filters, tabs). The default is `false`, which accumulates orphan ScrollTriggers on every render.
- Anything created *after* the callback finishes — click handlers, timeouts, observers — escapes the context and leaks. Wrap in `contextSafe()`.
- Every file using GSAP or Lenis needs `"use client"`. Keep those to small leaf components; never mark a layout or page client just to animate a heading.

**Reduced motion — the rule that prevents the classic bug:**

- **Never put a hidden state in CSS.** No `.reveal { opacity: 0 }`. Use `gsap.from()` so the element's resting state is its natural CSS state — content stays visible if JS never runs.
- Branch with `gsap.matchMedia()`, and give the reduce branch an explicit `gsap.set(..., { autoAlpha: 1 })` so GSAP owns the style and can revert it.
- Disable Lenis entirely under reduced motion.
- Use `autoAlpha`, not `opacity` — it toggles `visibility` too.

**Refresh discipline:** call `ScrollTrigger.refresh()` after images load, after `document.fonts.ready`, and on route change. Triggers computed before images have intrinsic height are wrong by hundreds of pixels. Set explicit `width`/`height` (or `aspect-ratio`) on every image.

## Performance budgets — non-negotiable

- **LCP ≤ 2.5s · INP ≤ 200ms · CLS ≤ 0.1**
- Total JS ≤ 170kb gzipped on first load.
- Animate **only `transform` and `opacity`**. Never `top`/`left`/`width`/`height`/`filter`.
- Never read `getBoundingClientRect()` inside a scroll callback after a write.
- Use `ScrollTrigger.batch()` for repeated elements rather than one trigger each.
- `will-change` sparingly — each promotion costs GPU memory.
- **Do not fade the hero in from `opacity: 0`.** It delays LCP. Mask it instead.
- WebP by default; AVIF only on full-bleed heroes.
- Self-host fonts via `next/font`. No external font CDN request.

## Accessibility

- WCAG AA contrast on all text. **The client's brand blue will not pass on near-black at its logo value** — lift it for anything readable and keep the original only for the logo itself.
- Visible keyboard focus on every interactive element.
- `prefers-reduced-motion` honoured properly, per the rules above.
- Semantic landmarks; images carry real alt text describing the work, not the filename.

## Out of scope

Do not build these without an approved change order: Arabic / RTL, e-commerce, visitor accounts, a custom backend or database, news and careers modules, individual capability sub-pages, a process page. All are priced separately in the signed agreement.

## Content and legal constraints

- **Brand images may be restricted.** Luxury fit-out contracts routinely carry confidentiality covering a store's existence and its photography. Every project record needs publication-approval status and an anonymised descriptor field. Default new records to *not publishable*.
- The anonymised form is standard in the sector: *"Swiss watch maison — Dubai Mall — 340 sqm full fit-out, 14-week programme"* with detail crops rather than identifying wide shots.
- **Fonts:** any typeface supplied by the client must carry a valid **web** licence. Desktop and print licences do not permit webfont use. If none is available, use Fontshare (ITF Free) or Google Fonts (OFL).
- Never commit client photography that has not been approved for publication.

## Working conventions

- **Do not run `npm install` from an agent shell.** Installs happen on the developer's macOS machine; a Linux agent VM would write incompatible native binaries.
- Small, focused commits. Present-tense subject lines.
- No secrets in the repo. `.env.local` is gitignored; add an `.env.example` when Sanity arrives.
- Third-party accounts — domain, Vercel, Sanity — are registered in the client's name, not ours.
